# English Assessment Test - Flask App

This repository contains a simple Flask application designed to provide an English assessment test inspired by Capgemini's evaluation rounds. The application evaluates users on three core skills:

1. **Reading**: Assess comprehension and interpretation skills.
2. **Writing**: Test grammar, vocabulary, and expression.
3. **Listening**: Measure understanding of spoken English.

## Requirements and Installation 

1. **Ollama**: Install from the [Ollama website](https://ollama.com/).
2. Run the provided `2bat` files and delete them after execution.

## Features
- **Reading Assessment**: Analyze text comprehension with a series of interactive questions.
- **Writing Tasks**: Use advanced language models (via LangChain and Ollama) to evaluate written responses.
- **Listening Section**: Leverage Google Text-to-Speech (gTTS) to deliver audio-based questions.
- **Interactive and User-Friendly**: A clean and minimalistic interface for seamless user experience.

## Technologies Used
- **Flask**: Backend framework to serve the application.
- **LangChain**: Framework for integrating language models for text analysis.
- **Ollama**: Natural language processing for evaluating user responses.
- **gTTS**: Generate audio questions for the listening assessment.
